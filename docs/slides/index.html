Notes

Search with the real files

Slide 01

The chat model writes. This service only searches. The useful part is that the search is over the company’s own documents, not the public web.

The problem

Slide 02

An agent with no company files will still answer. The answer is about companies in general. It cannot know who emailed, or what this wholesaler’s return rule is.

Real information

Slide 03

Claude calls search. The brain returns a few passages, with filenames. The agent writes from those. That is how the answer gets better: the information is real, and it is this company’s.

RAG

Slide 04

The question is embedded with the same small model as the files. The closest chunks come back, merged with a keyword match. The agent then writes. One passage is enough when the whole answer sits in that passage.

The gap

Slide 05

Arun’s email and the seven-day rule do not live in the same file. Similarity can rank the email first and never surface the price list. The shared product is the missing step.

Graph RAG

Slide 06

On ingest, the service records people, companies, and products, and the links the ontology allows. Search still starts with the closest chunks. A chunk that shares a name, or sits one or two links away, can be added. It is marked Connected. On the 9 Nov check that line on the price list was Company: Northline Wholesale, not the product name.

The check

Slide 07

Asked in Claude on 9 Nov 2026. With the key on, Claude said Arun Shah of Kedron Street Kitchen, account KSK-19, emailed accounts@northline.example on 4 Nov asking to return 3 unopened 1-litre bottles of light soy sauce, SKU NL-SOY-1, from the 26 Oct delivery. The price list allows unopened dry goods back within 7 days. His email puts the ask at 9 days, so the request is outside that rule. Opened bottles cannot be returned, but these were unopened. Invoice 1047, dated 3 Nov, is a 4-pack rice order and does not show the soy purchase. No reply to Arun is in the files. Sources Claude named: demo/email-kedron-soy-return.md, price-list.md, demo/invoice-1047.md.

The same question with the key off still returned the Kedron email and the 7-day sentence, and Claude reached the same conclusion. It did not bring in invoice 1047, and the tool printed no Connected line. With the key on, the price-list passage carried Connected: Company: Northline Wholesale.
